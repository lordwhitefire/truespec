How the independent enumeration works (materially different from the extractor)
- Same-origin sheets: read live `document.styleSheets[i].cssRules` from the browser.
- Cross-origin sheets (Google Fonts, Font Awesome) throw SecurityError on cssRules, so the
  text is fetched with the browser's own User-Agent and re-parsed via
  `new CSSStyleSheet().replaceSync(text)` + that sheet's own `cssRules` — i.e. the
  enumeration/parse is the browser's CSSOM, not the extractor's hand-written parser.
  (Only the byte text is fetched, as the page itself fetched it; caching makes re-runs offline.)
