## What changed

- **One off-state vocabulary — `components/whatsapp.ts`.** `WA_OFF_TEXT`, `WA_OFF_REASON`,
  `waClass(base, off)` (adds `wa-off`) and `waOffProps(off)` — `role="link"`,
  `aria-disabled="true"`, `tabIndex={-1}`, `title={WA_OFF_REASON}`. There is no `href`, so the
  control is not a link and not in the tab order; the role/aria keep it a **switched-off control**
  rather than plain text, and the title is the reason. Every chat affordance uses the same two
  helpers, so the class and the reason cannot drift between surfaces.
- **`app/reference.css`.** `.wa-off` grey: `filter: grayscale(1); opacity: .5; cursor:
  not-allowed`. The `.wab` shine is removed (`.wa-off.wab::after { display: none }`), and the
  hover lift/shadow is cancelled on `.wab`, `.fab` and the showroom `.btn`; `.ofr`
  (“Make an offer”, “Book a viewing”) keeps its base background/padding on hover, and the footer's
  `.sq a` keeps its base colours. `.inf b.off-note` makes the header line read as a note, not a
  value (muted, 13px, normal family).
- **Every chat control keeps its place:**
  - header number line (the visible reason), nav chat, footer icon, footer “WhatsApp us”, floating
    control (`layout.tsx` + `SiteFab.tsx`);
  - home “Chat with us” (`app/(site)/(home)/page.tsx`), home empty state
    (`HomeInventory.tsx`), inventory empty state and farewell dialog (`InventoryBrowser.tsx`);
  - car `#wa`, `#of`, `#vw`, mobile bar `#mw`, sold view (`car/[ref]/page.tsx`), car not-found view
    (`car-parts.tsx`), site 404 (`app/(site)/not-found/page.tsx`), root 404 (`app/not-found.tsx`);
  - the markup generated by `HomeBehaviors` and `CarBehaviors` (farewell, “welcome back”, morning
    greeting, spoken links) — `role="link" aria-disabled="true" tabindex="-1" title="…"` plus the
    `wa-off` class when there is no number.
  - the privacy contact sentence is **not a control** (it renders “WhatsApp” as text, no anchor);
    nothing to grey.
- **`wa-number.mjs`** gained an optional run label (`… clear|restore task30`) so the Task 30
  backup/readings live beside its own evidence instead of overwriting Task 29's record.
- **`wa-off-drive.mjs`** (new) — the live witness below: 2 widths × 4 pages + the inventory
  farewell's own chat control, screenshots, and a visibility comparison between the two legs.
